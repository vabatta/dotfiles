The idea

Skills load on demand. The host reads the one-line description of each skill and loads the one that matches. The description alone decides the trigger. You call most skills as entry points. Other skills run the building blocks. The agent applies principles, and you never call them. There are five layers: the always-on rules, the journeys, and three kinds of skill.

Rules

Always on

Four global rules load in every session in Claude Code and opencode. They apply to everything below and need no trigger. Each rule names a principle that the agent then loads.

Journeys

Start here for a situation

A named entry point for one real situation. It sets where you start.

Process

One workflow, several skills

A named phase that puts other skills in order: design, plan, review, debug. Run it directly, or let a journey call it.

One-shot

One skill, one job

A single invocation that produces one thing: a trace, a verdict, a diagram, or a fix.

Principles

Rules, applied inline

Narrow policies. The agent loads a principle when its trigger matches and obeys it while it works. A principle does not run. It constrains.

    Journeys start from your situation. Each step names the skill to call.

    A journey is a preset entry point for one real situation. Journeys are grouped by family, and you can add more. A step lists only the skills that you call. Between the skills in one step, then means in order, or means pick one, and + means do both. A uses line shows the building blocks that the step runs for you. An applies line shows the principles that apply to the step. A branch line says when to do a step or skip it. The global rules above apply to every step: state the stack and the budget, verify the real artifact, and continue on reversible work. A done line says only what the steps produce. Nothing runs the journey for you.
