# Bro

Restate your last message so it lands.

1. Find the point of the last message. Done when you can say it in one sentence.
2. Rewrite it simply and concisely, like one human talking to another. Add a little context. Use the project's ubiquitous language; **domain-modeling** owns the glossary, including the map to the right one when the repo has more than one context. With no glossary, use the plain words the user used.
3. Write in ASD-STE100 Simplified Technical English (see **simple-english**) with no jargon. Done when a reader outside the project can follow it and nothing from the original is lost.
